# 第四幕快捷传送配置

本地成品版本：2026.09.28.3。LiteHub、BoHub 支持；NullHub 仅更新品牌区域。

入口：设置 → Mod 管理 → LiteHub / BoHub → 设置 → 第四幕快捷传送。
六个选择框对应第四幕传送页第 4–9 项，前三项不变。默认依次为：

1. 崔凡克
2. 法师峡谷
3. 地下墓穴二层
4. 憎恨囚牢二层
5. 神秘避难所
6. 苦痛大厅

名称从本机游戏版本 93854 的 `levels.txt` 与 `levels.json` 提取，内部目的地键
来自原版 `actinfo.txt`。参考 JCY 控制器的 `modify_act_info`；只改第四幕行的
`waypoint4` 到 `waypoint9`，不改游戏解锁条件、其他幕或其他表字段。

保存需关闭游戏，使用 Mod 的 `-txt` 启动参数后重启生效。“恢复默认顺序”只改
编辑草稿，点击保存才落盘。允许空项，拒绝重复或未知目的地。配置以实际传送表为准，
使用表内容摘要防止旧界面覆盖新修改。写入与 Hub 的启动、Mod 加工、安装共享互斥锁；
外部启动的 D2R 进程也会阻止保存。

`d2rhub-waypoints.json` 标识可配置能力。保存同步更新增强清单中的传送表摘要和大小，
通过持久化回滚记录覆盖表和清单的两次原子写入；中断后下一次读取/保存会在游戏关闭时恢复。

LOGO 链接现为 https://gitee.com/garyi7e/d2-rhub_-resource ，下方显示“感谢 JCY”。
URL 中转面板将打开与卸载计时器设为同帧到期，消除旧 0.1–0.3 秒窗口内的重复发送。
没有增加开机打开浏览器或后台联网动作。

验证：Rust 传送表/校验测试、界面保存/默认顺序/错误保留测试、现有 Mod 管理界面测试、
TypeScript、逻辑检查及 NSIS 本地构建通过。浏览器实际打开次数、跨幕传送和空项行为仍需游戏内确认。
本次为本机成品与 Hub 本地安装包，未发布远端更新。
