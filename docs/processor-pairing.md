# 加工器内置与模块协议

加工器从 Hub 安装资源 `processor/d2r-audio-mod.exe` 调用，不从历史下载缓存解析。
安装文件 SHA-256 与编译时记录核对；损坏时修复 Hub，不下载独立加工器。
不再使用软件版本互认、`hub-compatibility` 或 Hub 身份环境变量。

兼容性由功能组的协议、配方及结构校验决定。房间模块 r33：创建保持 10ms 打开暂停、50ms 退出/创建/关闭；加入表单按钮和回车直接发送 `JoinGame:JoinGame`。默认地狱保留。双 Esc r4 移除 HUD 中的 `D2RHubCloseEscArm` 定时器，保留暂停与过渡面板清理和 500ms 接收窗口。

同名更新从旧清单恢复模块和声纹参数，以原始源 Mod 重新生成后事务替换。只有协议兼容的增补才以旧成品为底。未知模块无法重建时停止，保留原文件。批量操作复用这两条路径，逐项串行，失败不阻断后续项目。
