# D2RHub v0.9.104

- 新增 GitHub / Gitee 双源更新与资源下载，可选择自动、优先 Gitee 或优先 GitHub。清单和文件均支持失败切源，下载完成后校验大小与 SHA-256。
- 软件安装包改为应用内下载，显示进度；校验通过后由用户点击安装，并再次核对安装包真实版本。
- Mod 加工器与官方 Mod 独立分发，不再把加工器放入 Hub 安装包。已安装资源与软件共用自动检查设置，自动检查只提醒，不自动覆盖。
- 官方 Mod 支持原位更新、旧目录备份和中断恢复；已加工、修改或来源不明的目录受到保护。兼容性检查与防降级校验覆盖软件、加工器和资源。
- 使用须知确认记录独立于软件版本保存，升级后不再重复要求确认；存储或运行服务出错时保留确认记录并支持重试。
- 修复下载等待响应期间的取消处理，以及并发检查更新时旧清单覆盖新缓存的问题。
- 新增维护者本地一键发布入口，可自动构建、打包、双端校验发布和失败补传。

本次加工器及 LiteHub、BoHub、NullHub 内容均未变化，继续使用原有资源版本。当前官方 Mod 对应游戏数据版本为 `93854`。

旧版 Hub 尚不具备 Gitee 下载能力。GitHub 无法访问时，可从 Gitee 手动下载本版本完整安装包完成首次升级，之后使用应用内双源更新。资源和索引 Release 不会被当作软件正式版。
