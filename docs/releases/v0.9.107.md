# D2RHub v0.9.107

- 设置按游戏、扩展、应用组织，Mod 库与下载分开；加工草稿支持返回、取消和失败恢复。
- Mod 管理新增 MPQ 解压、原包备份和中断恢复；LiteHub、BoHub 可配置第四幕的六个额外快捷传送位置。
- 更新 LiteHub、BoHub、NullHub 成品资源，包含主菜单标识与链接调整，LiteHub、BoHub 同步新的快捷传送配置。
- 独立 Mod 加工器升级至 `1.4.0-beta.18`，支持 MPQ 转换，修复局内创建默认地狱及创建、加入的延迟提交。已有房间工具成品需要重新加工并重启游戏才能使用配方更新。
- 登录跳过动画按键仅在前 20 秒发送，更新赞助者名单。
- 加强 Mod 文件操作互斥、加工子进程回收、资源完整性检查，以及发布来源和双端下载校验。

## 版本号纠正

上一版 `0.99.106` 是版本号误填，本版恢复为 `0.9.107`。已安装 `0.99.106` 的用户请从本 Release 手动下载安装包，旧客户端可能不会提示此次更新。本版会正确处理缓存中的误填版本，后续恢复正常更新。

加工器与三个 Mod 已独立发布至 GitHub、Gitee；本版内置资源清单包含本次更新的真实下载地址、大小与 SHA-256。原游戏 Mod 目录保持不变。

## 验证范围

发布工作流执行前端、Rust 和发布器检查，构建 NSIS 安装包，并保存源码提交及检查证据。资源已重新核对文件摘要，双端附件通过匿名下载校验。自动检查不等同于真实游戏中的登录、音频、跟房、快捷传送和安装器覆盖升级验收；成品清单保留原有的运行验证状态。
