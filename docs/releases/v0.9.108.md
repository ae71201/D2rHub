# D2RHub v0.9.108

- 修复新版 LiteHub、BoHub、NullHub 因使用 `enhancement-manifest.json` 而显示“无法确认此目录的来源”的问题，同时修复资源下载后的身份校验失败。
- 保留旧 `generation-manifest.json` 格式兼容，校验 Mod 名称、方案、启动参数和游戏数据版本。
- 手动复制的成品与发布包内容一致时，可在下载校验后接管；忽略清单排版差异和可再生成的游戏 BIN 缓存，继续保护本地修改及加工成品。
- 沿用已发布的三个 Mod 和加工器 `1.4.0-beta.18`，不更换资源文件。

## 从旧版升级

- 0.9.104、0.9.105 未缓存误填版本时，可正常检查软件更新。
- 若提示“清单试图降级或替换同版本的不同文件”，完全退出 Hub（包括托盘），解压本 Release 的 `D2RHub-update-cache-repair.zip`，双击 `repair-update-cache.cmd`，然后重新打开旧版并检查更新。工具仅将已知 `0.99.106` 的软件更新缓存移到同目录备份，保留账号、设置、Mod 和下载文件；异常或不相关的缓存不会被改动。
- 已安装误填版本 `0.99.106`，或使用没有新版更新通道的更早版本，请直接下载本 Release 的安装包并安装。本版继续兼容误填版本缓存。
- 已加工、修改过或缺少可识别来源记录的 Mod 仍受保护，请先将其备份到其他目录，再安装新的成品；不会因名称相同就自动覆盖。

新版软件无法远程修改旧客户端的版本比较逻辑，因此这次缓存修复或手动安装只需执行一次。无需删除账号配置或重建游戏目录。
