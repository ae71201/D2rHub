# D2RHub v0.9.109

- Mod 设置新增游戏数据版本编辑，只有可验证的 Hub Mod 及其加工成品可以使用。保存时同步版本记录和校验值，检查游戏占用、编辑冲突，并支持中断恢复。
- LiteHub、BoHub 加工后即使改名，也可继承第四幕快捷传送设置；NullHub 及其加工成品只提供数据版本编辑。
- 新加工和同名升级会保留 Hub 来源记录。旧 beta18 加工成品可借助同目录中的原始 Hub 成品恢复来源；缺少可验证来源时继续保护现有内容。
- 声纹、跟房、双击 Esc、死亡退房仍按实际加工的功能开放，不会因来自 Hub 就自动启用未加工的功能。

数据版本编辑仅修改游戏读取的版本标记，不会转换数据表或自动适配新补丁。保存前请关闭游戏；本地修改和加工成品不会被资源更新直接覆盖。

## 资源与升级

继续使用现有 LiteHub、BoHub、NullHub 和 `1.4.0-beta.18` 加工器，不重复发布资源。

0.9.108 用户可直接检查软件更新。0.9.104/0.9.105 如被误填的 `0.99.106` 缓存阻止升级，请完全退出 Hub，解压本 Release 的 `D2RHub-update-cache-repair.zip`，运行 `repair-update-cache.cmd`，再检查更新。工具会保留备份，不修改账号、配置或 Mod。已安装误填版本 `0.99.106` 的用户请直接下载安装本版。

已验证三个真实 beta18 加工成品的版本编辑、快捷传送与加工能力保留；这不代替游戏内实机验收。更多说明见 [Hub Mod 设置与继承](../hub-mod-settings.md)。
