# D2RHub v0.9.110

- 账号快捷配置使用浮层，避免展开时挤动其他账号；运行中账号提供聚焦入口，删除独立确认，拖动使用专用手柄。
- 启动方案改为横向布局并提供独立编辑区；设置页、Mod 管理与跟房快捷配置统一控件样式。日志保留用户的展开/收起选择。
- 窗口切换请求串行处理，连续快捷键只保留最新待处理请求；异步恢复窗口，移除输入队列绑定。升级后首次启动重新计算默认窗口尺寸，随后保留用户调整。
- 未编辑的加工草稿返回时自动清理，已编辑草稿可继续编辑或主动放弃。

## 加工器 1.4.0-beta.19

- 局内创建和加入均在确认后 50ms 发出退出请求、60ms 提交，不主动关闭提交控制器。
- 移除加工器注入 HUD 的 Esc 接收器清理定时器；保留暂停菜单、动作切换和超时清理，修复 BoHub 等常驻 HUD 场景下双击 Esc 不生效。
- Hub 校验同步至房间工具 r31、双击 Esc r3，旧配方允许升级。

先更新 Hub，再更新加工器并重新加工已有 Mod，重启游戏后生效。此次不重发 LiteHub、BoHub、NullHub 基础资源，也不修改声纹协议或音频资源。

用户已在 BoHub 来源的 testbo 中确认跟房和移除 HUD 清理后的双击 Esc 有效。60ms 是客户端定时器设置，不代表服务器确认退出；连续切房、不同网络条件和各类源 Mod 仍有实机差异。短暂显示主界面后自动进入下一局不单独认定为失败。

发布流程从干净源码快照执行前端检查、Rust 格式/Clippy/测试并构建安装包与加工器，上传后核对双端匿名下载摘要。自动检查不代替真实账号登录、多开性能和 Windows 前台焦点的完整实机验收。
