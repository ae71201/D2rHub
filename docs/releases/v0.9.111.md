# D2RHub v0.9.111

配套加工器：**1.4.0-beta.20**。先更新 Hub，再到“Mod 管理 → 下载与更新”安装配套加工器。

## 配套校验

- 加工器安装和每次加工前，校验文件大小、SHA-256、实际产品身份、版本与配套协议。加工器也会检查 Hub 身份。
- 互认失败时禁止加工、增补、升级、MPQ 转换和恢复；不再使用旧版或调试目录中的加工器回退运行。
- 加工页、下载页和更新通知明确说明禁止加工及更新要求。导入本地 EXE 同样检查，无法绕过。

## 自动跟房

- 高级输入时序增加小号首次补发回车等待、补发间隔和次数，默认分别为 1000ms、1000ms、4 次；次数不包含首次提交，设为 0 可关闭。
- 每个小号独立计时，不重新打开或填写表单，不向主号补发。取消、模块停用、发送失败或目标身份变化时停止。
- 旧配置自动补齐默认值，保留原有时序；固定次数补发不代表游戏已成功加入房间。

## 房间工具 r32

配套加工器恢复局内创建/加入在确认后 10ms 打开暂停菜单，50ms 按子节点顺序退出、提交、关闭控制器。双击 Esc 保持 r3，音频协议保持 v7。已有 Mod 需要重新加工，所有使用该成品的账号需要重启游戏。LiteHub、BoHub、NullHub 基础资源沿用现有版本。

本版验证包含前端、Rust、配套握手及 CLI 拒绝路径、发布产物版本和下载摘要检查。自动验证不等同于真实游戏入房确认；不同网络条件下的连续切房仍需实机观察。
