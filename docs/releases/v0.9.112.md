# D2RHub v0.9.112 · 2026-09-30

本版将 `d2r-audio-mod 1.4.0-beta.21` 内置到 Hub 安装包，不再单独下载加工器。安装资源按 SHA-256 校验，模块按协议、配方和布局校验兼容性。加工器损坏时请修复或重新安装 Hub。

- Mod 支持批量新建、增补和同名重做：先检查目录并预览计划，再逐项处理，失败项目可重试；完成后刷新目录状态。
- 同名重做从未经加工的原始 Mod 恢复旧模块配置，事务替换目标；无法解释的新配方或未知模块会停止操作并保留原文件。
- 房间工具 r33 的加入表单直接发送原生 JoinGame 消息；创建保留原时序和默认地狱。
- 双 Esc r4 删除 HUD 中关闭 Esc 接收器的旧定时器，保留暂停、过渡面板清理和 500ms 窗口。已有加工成品需要重新加工并重启游戏。
- 移除小号补发回车及其设置。旧字段读取时忽略，保存时清除；后台同步按键的单条消息等待上限由 250ms 调整为 1000ms。
- 发布指定任务 `20260929142304-7e08a9da` 的 BoHub 静音资源；LiteHub、NullHub 内容未变，保留原资源版本。三个资源使用游戏数据版本 `93854`。

升级请下载完整安装包。旧加工器缓存不再作为本版加工入口；受管 Mod、账号与配置继续保留。BoHub 静音听感及真实游戏中的跟房、双 Esc 行为仍需游戏内确认，自动测试和资源摘要校验不代表实机验收。

发布流程与检查证据见 [发布指南](../release-workflow.md)，当前变更验证见 [审查记录](../review-20260930.md)。
