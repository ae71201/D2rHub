# D2RHub v0.9.113 · 2026-10-09

本版新增窗口布局和无需账号的外部游戏识别，完善多账号操作、启动后的战网保留及自动跟房诊断。安装包继续内置 `d2r-audio-mod 1.4.0-beta.21`，Mod 协议与资源版本保持不变。

- **窗口布局**：保存多屏布局，按实际启动顺序分配位置；支持拖动预览、坐标输入、边缘吸附，以及把运行窗口的位置存为账号位置配置。
- **游戏分辨率**：布局中的分辨率与账号分辨率含义一致，启动时写入 `Settings.json` 的 `Screen Resolution (Windowed)`，不会被任务栏或较小的显示器工作区裁小。“恢复布局”只恢复位置及层叠顺序，修改分辨率需要重新启动游戏。
- **外部游戏识别**：配置游戏目录和识别 Mod 后，可明确选择外部启动的 D2R 进程，无需创建 Hub 账号。即使只有一个游戏进程也需要手动选择；进程退出后需重新选择。识别和统计记录保留独立来源。
- **批量账号操作**：可全选可启动账号或运行中账号，状态未确认或配置异常的账号不会加入启动选择；关闭选中账号与关闭所有 D2R 进程明确区分。
- **账号与启动**：改名同步更新运行中的游戏窗口，避免启动重试覆盖新昵称；战网初始化登录等待延长至 600 秒。可选择在整个启动批次成功后重新打开某个账号的战网客户端，取消或失败时跳过。
- **自动跟房**：同步按键的消息超时可配置，默认 2000ms，范围 250–5000ms；失败或取消后清理按键状态，不重复发送按下动作，并保留账号、步骤和系统错误码以便排查。
- **桌宠与界面**：新增翅膀、光环及日常饰品和双语对白；改善账号标签、输入焦点和布局编辑反馈。
- **可靠性**：修复大量进程扫描输出导致的管道阻塞，以及取消拖动后下一次拖动不实时更新的问题。

从 v0.9.112 升级时，账号、位置配置及统计数据保留；窗口布局和战网保留默认关闭。本次不要求因 Hub 更新重新加工已有兼容 Mod，也不更新 LiteHub、BoHub、NullHub 资源。

操作步骤见 [使用手册](../user-guide.html)，发布与检查证据规范见 [发布指南](../release-workflow.md)。
