# D2RHub v0.9.114 · 2026-10-09

本版改进窗口布局与游戏启动期间的账号识别。安装包继续内置 `d2r-audio-mod 1.4.0-beta.21`，沿用现有 Mod 协议、资源文件及摘要。

- **窗口对齐**：位置采集和恢复统一使用窗口可见边缘，补偿 Windows 隐形缩放边框，减少保存位置与实际显示之间的偏差。
- **布局预览**：画布、预设、吸附和居中计算包含标题栏与可见边框。分辨率仍表示游戏内容尺寸，修改后在下次启动时生效；恢复布局不改变运行窗口的大小。
- **负坐标**：允许窗口向工作区左侧或上方移出，同时至少保留 64 像素可见区域。
- **自动校准**：启动后使用稳定窗口测量边框；同一显示器、DPI 和窗口样式只由一个实例负责测量，失败可由其他实例接替。校准结果保存供后续使用，用户已手动调整或恢复的位置不会被启动校准覆盖。
- **账号识别**：保留已启动游戏的原始进程句柄，避免加载阶段无窗口或窗口标题重置时丢失运行状态，并持续修复账号窗口标题。

旧配置缺少边框校准数据时自动使用默认值。已有账号、布局及统计数据保留；旧位置数值保留，新版按可见窗口边缘解释，可重新采集位置以精确对齐。本次无需因 Hub 更新重新加工已有兼容 Mod。

操作步骤见 [使用手册](../user-guide.html)，维护者发布流程见 [发布指南](../release-workflow.md)。
