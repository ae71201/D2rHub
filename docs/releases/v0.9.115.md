# D2RHub v0.9.115 · 2026-10-20

本版新增视觉识别、协作跟房和完整启动方案，安装包内置 `d2r-audio-mod 1.4.0-beta.22`。

- **视觉识别**：地区和恐怖区域通过游戏画面文字识别；低置信度掉落可通过地面标签核验。首次使用下载并校验 OCR 模型与推理运行库，诊断日志默认关闭。
- **协作跟房**：增加拼房创建和跟随模式，通过聊天标记触发本机房间规则，保存去重记录；修改规则或显式重置后建立新的监听基线。
- **启动方案**：保存账号游戏设置、区服、Mod、识别、跟房和窗口布局快照；本次运行的设置独立于保存的方案，并支持进程身份核验后的会话恢复。旧方案需编辑保存后使用。
- **窗口布局与统计**：采集当前运行窗口布局，改进显示器身份稳定性；统计页新增场景时间占比和交互式单局时长图。
- **Mod 加工**：配方升级到 r26，掉落声纹组 r4，不再生成地区、恐怖区域或主界面声纹；增加独立敌对重开、场景重开和玩家尸体拾取按钮。场景重开使用游戏原生流程，需在第三幕、崔凡克或第四幕小站处操作。
- **敌对重开**：可选择只操作监听窗口或所有受管窗口；监听来源不随操作范围扩大，目标需要相应 Mod 能力。
- **操作界面**：整理首页和自动化设置，修正默认选项，同步使用手册及标注截图。

## 升级与资源

账号与统计数据保留。旧 r22–r25 声纹成品不能作为新版加工的干净来源，请选用原始 Mod 或重新下载纯净 LiteHub、BoHub、NullHub 后加工，并重启游戏。新版模块布局不能仅修改配方号冒充升级。

三个下载资源仍是未加工的源 Mod，加工器随安装包提供。资源发布会逐文件核对来源清单、大小和 SHA-256，内容未变化时保留原资源版本。现有纯净资源的格式与本版兼容，目录兼容上界调整为 `0.9.116`（不含）。

视觉资源独立按需下载，固定模型和 ORT 1.22 接口并核验摘要；资源不可用时界面报告状态。视觉识别需要游戏画面可采集，掉落核验需要地面标签可见。

操作步骤见 [使用手册](../user-guide.html)，发布和补传步骤见 [发布指南](../release-workflow.md)。
