# D2RHub v0.9.116 · 2026-10-20

本版改善视觉识别资源的国内下载与管理体验，并保护场景重开的传送点配置。

- **国内镜像**：OCR 模型与 ONNX Runtime 增加 Gitee 资源库镜像，遵循软件的下载源设置；默认自动模式在没有地区缓存时优先 Gitee，下载失败会回退到原始来源。所有来源继续校验文件大小和 SHA-256。
- **统一资源包**：在 Mod 管理的“下载与更新”页统一展示“视觉识别资源包”，支持提前下载、校验资源、查看整体进度及打开资源目录。资源由所有账号和游戏版本共用。
- **自动准备保留**：启用相关识别功能时仍自动准备缺失资源，已有有效缓存直接复用；手动和自动准备共用下载流程并串行执行。
- **场景重开保护**：已加工场景重开的 Mod 锁定第四幕快捷传送编辑；重新加工或更新时不恢复旧传送点偏好，保留场景重开需要的小站映射。

模型仍为 PP-OCRv5 mobile（RapidOCR v3.10.0），推理运行库仍为 ONNX Runtime 1.22.0。加工器 beta.22、配方 r26 和声纹 r4 均不变，无需因本次更新重新加工 Mod。

现有账号、设置和统计数据保留。纯净 Mod 的资源文件、版本与摘要不变，仅扩展本地兼容范围至 `0.9.117`（不含）。
