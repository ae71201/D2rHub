# D2RHub v0.9.117 · 2026-10-21

本版调整启动方案的设置归属，改善地区与聊天视觉识别，并增加局内建房难度选项。

- **共享运行设置**：启动方案保存账号组合、跟房角色、识别账号、布局和启动差异；跟房规则、延迟、识别过滤、悬浮窗及启动行为统一使用最新公共设置。方案不指定跟房或识别账号时暂停对应能力，保留公共开关。
- **账号游戏设置**：默认在每次启动时读取账号配置，也可显式开启独立覆盖。旧完整方案自动迁移，原始配置备份为 `%APPDATA%\D2RHub\global_config.before-shared-schemes.json`，正在运行的会话保留已解析的游戏设置。
- **地区识别与计时**：补充简繁体地图及入场提示译名，收紧红字颜色检测，并区分未知名称与歧义名称的诊断。同名地区按规范名称合并，七座塔·拉夏之墓及同名下水道不再因不同 Area ID 被拒绝；楼层和不同名称仍分别计时，历史记录保留。
- **拼房聊天信号**：主机创建前连发三条 `*********** 077 ***********` 格式消息；接收方检查两侧符号布局，仅裁切数字送入 OCR，覆盖 720p 与 1080p 样本。保留旧消息基线、持久去重及冷却机制。主机和跟随端均需升级，旧加号消息不再触发。
- **创建默认地狱**：单项及批量 Mod 加工可关闭局内创建默认地狱；同名更新、重做和失败重试保留选项。已有 Mod 默认保持开启，仅需在改变该选项时重新加工。
- **资源目录**：修复视觉资源包“打开目录”的 Windows 路径分隔符，并更新赞助名单。

内置加工器仍为 `1.4.0-beta.22`，模型、推理运行库、声纹协议和模块版本保持不变。LiteHub、BoHub、NullHub 的资源文件、版本及摘要不变，本地兼容上界扩展至 `0.9.118`（不含）。

自动检查和截图回归不代表完整游戏内验收；实际登录、跟房输入时序、难度选择及不同字体的识别效果仍以游戏内表现为准。
