# 2026-09-30 当前变更 review

范围：D2RHub 与相邻 d2r-audio-mod 工作区的当前变更，重点为内置加工器、Mod 下载迁移、批量加工、同名重做、补发回车删除和 HUD Esc 接收器清理。保留已有暂存变更，未提交、发布或修改正在运行的游戏 Mod。

## 已修正

1. 删除小号补发回车的执行循环、前后端字段、默认值、范围验证、设置控件及当前使用说明。旧字段可被读取但不再序列化，原有其他时序保留。
2. 独立双 Esc 与房间工具加工路径均移除 HUD 的 `D2RHubCloseEscArm` 定时器，不再重新插入。保留暂停和过渡面板清理及 500ms 窗口。加工器 r4 指纹与 Hub 验证一致为 `hud_cleanup=0`。
3. 批量执行完成后重新读取 Mod 状态，避免返回修改时使用过期名称占用、模块配置；读取失败时清空旧检查结果，禁止无有效检查结果的预览。
4. 单项同名重做在执行前检查原始来源是否存在、已解压且未经加工。来源下拉框不再提供打包或已加工项目。
5. 旧资源清单迁移只豁免已知 0.9.111→0.9.112 互认范围，不再把任意不兼容或损坏的 Hub 版本范围改成兼容。
6. 重做拒绝比当前 Hub 更新的总配方和已知模块配方，避免把无法解释的新版本配置静默降为旧版本。未知模块仍拒绝重做。
