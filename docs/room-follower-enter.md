# 小号跟房补发回车

设置 → 自动跟房 → 高级输入时序提供三项配置：

| 配置 | 默认 | 范围 |
| --- | --- | --- |
| 小号首次补发回车等待 | 1000ms | 0–60000ms |
| 小号补发回车间隔 | 1000ms | 100–60000ms |
| 小号补发回车次数 | 4 | 0–20；0 关闭 |

次数不包含流程原本的首次回车提交。每个小号独立计时，默认在首次
提交释放按键后约第 1、2、3、4 秒各补发一次回车。不重新打开或填写
表单，不向主号补发，不改变小号之间原有的同时/间隔启动策略。

补发期间流程仍持有账号租约。取消、模块停用、发送失败或目标进程/
窗口身份变化时结束补发；不会留下脱离流程的后台发送线程。它是固定
次数的按键补发，不表示游戏已经成功加入，也不依赖入房成功检测。

旧配置缺少字段时补上默认值，并保留已有的输入时序。恢复默认时序会
同时恢复这三项设置。中英文面板与后端使用相同的默认值和范围。

加工器房间工具 r32 同时恢复确认后 50ms 按顺序退出、提交、关闭控制器。
使用该时序需重新加工并重启游戏；已修复的双击 Esc r3 保持不变。
